# Circular Economy Analytics Hub

Public static showcase for the Circular Economy Analytics Hub, a local research prototype for sensor-data analysis, model evaluation, model publication, and batch application in circular-economy scenarios.

This repository contains only the public showcase and evaluation materials. The main application source code, datasets, and model artifacts are not published here.

Reading order: Platform → Literature Atlas → Platform Mapping → Architecture → Evaluation. The atlas describes 85 research leads; the shared curated library contains 17 sources. Literature scope, executable candidates and measured model performance remain separate.

The site is exported from the local research repository with `scripts/build_showcase_site.py`. Public links stay within the published site; code module names identify the local implementation without publishing backend files. `build-info.json` records the source revision and SHA-256 hashes of the deployed pages and assets.
